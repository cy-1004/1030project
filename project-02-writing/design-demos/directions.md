# 项目二设计方向

共同内容：用“阅读与成长”学习心得展示主题输入、正文编辑、写作辅助和保存。屏幕目标 1440×900，并兼容手机；示例文字为本地演示稿。

- A 纸页工作室：中央纸页作为视觉主角，左侧导航、右侧写作要求；书页留白来自“需要安心阅读和修改文字”的工作场景。
- B 专注编辑器：深色单篇编辑区加底部操作面板，左侧展示结构；文稿占据屏幕主体，突出连续写作时的专注感。
- C 双栏创作台：左侧组织想法、右侧展示文章；左右对应从写作要求到文章内容的思考过程。
- D 纯粹稿纸：单栏阅读、按需展开工具。E 创作卡片：主题、提纲、稿件分步整理。F 编辑长桌：提纲、正文、建议并列。

前三个是可交互的 HTML 初稿，后三个是缩略候选。初稿按钮主要用于说明交互，尚未接入正式后端。
