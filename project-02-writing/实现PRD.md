# 产品二：智能辅助写作 Demo 实现 PRD

版本 V1.0｜独立入口 `http://<内网IP>:8102`｜前端目录 `project-02-writing/frontend/`｜共用 `backend/`

**实现状态**：已按用户选定的 A 版完成工作台、模板、草稿、收藏和版本对比。可通过 OpenRouter 实时生成，未配置 Key 或调用失败时使用本地演示样稿。版本差异按段落高亮；生成使用普通请求，取消仅停止前端等待；目标字数为提示，不保证精确。运行说明见本目录 `README.md`。

## 目标与演示

让用户从主题出发，在一个页面完成作文、诗歌或心得的草稿生成、编辑、改写和保存。默认演示：选“心得体会”→输入主题和三个关键词→生成文章→选中一段扩写→保存→打开历史版本对比。最终展示用户能获得一篇可编辑草稿和可追溯的修改记录。

## 页面与操作

| 页面 | 内容与交互 | 结果 |
|---|---|---|
| 写作首页 | 最近作品、三个文体入口、推荐模板 | 创建新稿或继续编辑 |
| 写作工作台 | 左侧大纲，中间正文编辑器，右侧写作要求及操作栏；主题、读者、字数和风格可选 | 生成、续写、润色、缩写、扩写、复制与保存 |
| 模板中心 | 展示并编辑作文、诗歌、心得的标题和章节结构 | 保存模板并用于新稿 |
| 版本与素材 | 文章版本列表、差异高亮、回退；收藏好句并插入 | 旧版本可恢复，收藏可复用 |

生成前有明确输入校验；生成中显示加载状态与取消；失败时提示并允许重试。选中段落时改写只替换该段，替换前可预览。修改后提示未保存状态。

## 数据与实现

优先复用 `tkmax-tools` 的 OpenRouter 文字请求、流式输出与版本记录思路；新写适合三种文体的提示词，不使用商品营销文案模板。共用后端提供 `/api/writing/templates`、`/api/writing/drafts`、`/api/writing/drafts/{id}/versions`、`/api/writing/generate`、`/api/writing/rewrite`，SQLite 保存稿件、版本、模板和收藏。通过后端环境变量读取 `OPENROUTER_API_KEY`，禁止把 Key 放前端。未配置 Key 或断网时，使用本地样稿和模板，清晰标注“演示样稿”；实时生成标注来源。

## 视觉与验收

安静的编辑空间：暖灰纸张、深色工具栏、可折叠大纲、清晰的段落层级。桌面三栏，手机单栏。至少 3 种文体、6 个模板、每种文体 2 个本地样例；三种文体均能生成可编辑草稿；改写前后可比较；保存后刷新和版本恢复有效；无外网可完成样稿演示。需确认：优先演示年级与写作主题；默认选初中作文、日常诗歌和学习心得。
