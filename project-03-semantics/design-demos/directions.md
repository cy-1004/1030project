# 项目三设计方向

共同演示内容：虚构数字展厅合同、客服工单和经营研报；原文、术语释义、实体、摘要与有原文依据的问答。桌面统一按 1440×900 检查，手机按 390×844 检查。

- A 深蓝分析台：左侧导航，顶部处理步骤，中间原文/结果并列，下方问答。色彩以深蓝、浅蓝和青绿组成，视觉主角是可点击的原文高亮及其解释。结构来自“人工阅读与机器整理需要同时对照”的内容关系。
- B 文档审阅台：浅色文档占主体，右侧汇集术语和实体，问答紧跟原文；视觉主角是清晰的文本阅读。结构来自“读一份材料、随时查注释”的阅读任务。
- C 语义任务中心：深青侧栏，上方整段原文，下方结果/问答并列；视觉主角是业务材料与处理结果的递进关系。结构来自“输入后再判断结果”的处理流程。
- D 规则调试器：规则与输入输出并列，强调工程调试。E 知识阅览室：阅读主导、解释按需展开。F 文档处理流水线：输入、分析、整理顺序式并列。

初稿的分析和问答使用本地虚构样例与简单匹配；导航仅显示方向，不承诺记录已保存。正式后端代码及数据库测试已准备，最终前端在方向确认后接入。
