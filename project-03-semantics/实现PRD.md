**当前进度**：后端模块已完成并在隔离数据库中通过验证；A/B/C 三个界面方向初稿位于 `design-demos/`，目前 8103 展示这些初稿。正式前端及后端运行接入将在方向确定后继续完成。

## 目标与演示

让业务人员将一段文本转成易读的释义、实体与问答结果。默认演示：选择合同场景→载入合同样例→分析→点击高亮术语查看解释→针对合同期限提问→打开规则命中记录。提供客服、合同、研报三个场景，同一多义词随场景改变解释。

## 页面与操作

| 页面 | 功能 |
|---|---|
| 语义工作台 | 输入文本或选择样例，切换场景，显示处理步骤、摘要、词语映射和高亮实体 |
| 文档问答 | 预设问题或自由提问，答案展示引用的原文片段，未找到依据时明确提示 |
| 术语与规则 | 词条增删改查、场景绑定、同义词、优先级和生效版本；沙箱即时试验 |
| 处理记录 | 查询输入输出、规则命中和版本，支持回看及复跑 |

至少 3 个文本样例、每个场景 10 个词条和 3 个预设问题。可视化流水线展示“预处理→术语映射→实体提取→结果整理”及启停状态，不必实现复杂拖拽编排。

## 数据与实现

共用后端 `/api/semantics/catalog`、`/terms`、`/rules`、`/analyze`、`/ask`、`/runs`；SQLite 记录词条、规则和结果快照。复用 `tkmax-tools` 的文字客户端和 PDF 文本提取思路；首版支持粘贴文本，文件上传作为可选增强。无 Key 时采用本地字典与预设问答；配置 Key 后可用模型对任意文本生成摘要和问答，但必须展示证据，不能虚构引用。输入若发送外部模型，页面提示用户使用演示材料。

## 视觉与验收

深蓝灰信息分析台，原文与结果并列，标签和连线清晰。验收：三个场景切换、同词不同释义、规则编辑后重跑结果变化、答案对应原文、历史记录可回看；断网时预置案例完整可演示。待确认行业文本；默认使用虚构合同、客服工单和研报。
