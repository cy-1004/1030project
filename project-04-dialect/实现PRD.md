# 产品四：智慧方言辅助学习 Demo 实现 PRD

版本 V1.0｜独立入口 `http://<内网IP>:8104`｜前端目录 `project-04-dialect/frontend/`｜共用 `backend/`

## 目标与演示

通过方言词句、音频与情景训练帮助用户理解关键词。默认演示：选粤语→服务接待→听词句→完成 5 道听音选词→模拟跟读和对话→查看成绩及错词。移动浏览器优先，电脑端展示手机样式。

## 页面与交互

| 页面 | 功能 |
|---|---|
| 学习首页 | 方言包、情景卡、学习进度和继续练习 |
| 词句详情 | 普通话与方言对照、读音、情景说明、播放和收藏 |
| 听音训练 | 音频播放、候选答案、正确/错误反馈、重听和近音提示 |
| 跟读与对话 | 按步骤展示对话；录音入口可选，手动选择听辨结果为稳定主演示路径 |
| 练习结果 | 命中率、反应时长、错词及复习入口 |

首版默认粤语与闽南语，各有问候、服务接待两个场景；每种方言至少 10 条经过核对的词句，训练题至少 5 题。音频和释义需核对，未核对内容不标为标准发音；缺少真实方言音频时明确标注示例，并保留文字训练。

## 数据与实现

后端 `/api/dialect/packages`、`/phrases`、`/sessions`、`/results`；词句和音频预置在本地，学习成绩保存 SQLite。可参考 `tkmax-tools` 的音频播放和语音转写交互；现有服务不保证方言识别或发音评分。默认演示不依赖麦克风或外网，录音识别如接入则明确标注实际能力和模拟反馈。

## 视觉与验收

亲切清晰的学习应用：方言地图、场景插画、醒目播放键、练习进度与错题反馈。验收：两个方言包和四个情景可浏览、听音题能计分、模拟跟读与四步对话可完成、结果可回看。待确认方言和真实音频来源；默认按上述范围准备。
