# 产品五：智能绘画编辑 Demo 实现 PRD

版本 V1.0｜独立入口 `http://<内网IP>:8105`｜前端目录 `project-05-painting/frontend/`｜共用 `backend/`

## 目标与演示

让设计人员从创意描述得到候选图，并进行对比、轻量编辑和素材收藏。默认演示：选择书籍封面主题→输入提示→得到四张候选→选择一张更换风格→A/B 对比→评分保存到资产库。

## 页面与操作

| 页面 | 功能 |
|---|---|
| 创作工作台 | 文本、参考图、风格、画幅、生成按钮、任务进度与四张候选 |
| 编辑画布 | 选区、风格切换、背景替换、前后滑杆、历史版本；清晰说明预置变体和实时生成的区别 |
| 版本对比 | 两张图并排/滑杆、评分、备注、选为最终稿 |
| 团队资产库 | 按主题、风格、时间查询，查看提示词、版本和下载 |
| 运行概览 | 模型预设、生成任务状态、作品数量和历史趋势；均来自本系统记录 |

首版 3 个主题、每主题 4 张本地候选图，至少 2 种编辑变体；图片由生成工具提前制作并本地保存。未知主题在离线模式提示可用范围，不假装生成了对应图。

## 数据与实现

复用 `tkmax-tools` 的 OpenRouter 生图调用、图片保存和版本/下载模式，精简会话与计费依赖。后端 `/api/painting/generate`、`/jobs/{id}`、`/assets`、`/assets/{id}/versions`、`/ratings`；SQLite 保存元数据，图片存本地。配置 Key 并允许外网时可实时生图；网络故障时预置素材可演示。参考图重生成不保证选区外像素不变，应明确显示；演示中的精确局部变化使用预置图层。

## 视觉与验收

深色设计工作台、大画布、缩略图胶片带及作品瀑布流。验收：本地主题能生成候选、切换两个效果、对比评分并保存下载；Key 可选，失败不影响预置演示。待确认实时生图预算、模型和允许发送的参考图范围。
