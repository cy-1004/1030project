# 产品六：智能图像识别运维 Demo 实现 PRD

版本 V1.0｜独立入口 `http://<内网IP>:8106`｜前端目录 `project-06-vision/frontend/`｜共用 `backend/`

## 目标与演示

围绕设备巡检影像，展示异常定位、告警和处置过程。默认演示：从总览选择一台设备→打开预置巡检图→查看裂纹标框和风险描述→创建工单→指派并记录处理→关闭告警→总览同步更新。

## 页面与操作

| 页面 | 功能 |
|---|---|
| 运维总览 | 设备数、巡检数、待处理告警、风险分布、区域示意及近期事件 |
| 巡检分析 | 样例图选择/上传、缺陷框和热点、类别/位置/等级/建议、质量异常提示 |
| 告警详情 | 原图/标注图、设备信息、历史对比、证据时间线与处置建议 |
| 工单列表 | 筛选、指派、备注、待处理→处理中→已解决 |

至少 6 台虚构设备、8 张本地样例图、3 类缺陷和 2 类画面质量问题。预置样例的标框和说明由人工标注，任意上传图可查看和手动标注。实时视觉模型如启用，输出“疑似异常”并要求人工确认，不视作可靠工业检测结果。

## 数据与实现

后端 `/api/vision/devices`、`/samples`、`/analyze`、`/alerts`、`/alerts/{id}`、`/workorders`；SQLite 保存设备、告警和工单，图片放本地。复用 `tkmax-tools` 图片上传和视觉请求封装。预置样例在无 Key、无外网时仍可跑完闭环；实时分析只在配置 Key 和允许外部传图后提供。

## 视觉与验收

深蓝灰工业运维界面，告警用橙红强调，突出真实影像、标注与处理时间线。验收：点击标框可看详情；工单流转后首页统计变化；刷新后记录保留；上传图不冒充自动检测；内网断网下预置样例可用。待确认设备行业与可公开照片；默认虚构电力设备和原创示意图。
